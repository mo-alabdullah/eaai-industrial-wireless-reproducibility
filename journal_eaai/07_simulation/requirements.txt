#  - Constraint mechanism (SELECTED): BSA-C-PPO uses a projected Lagrangian multiplier on the raw
#    additive episode-sum shortfalls, with one shared vector cost critic (J_cost = 3|C| + 1 = 7),
#    gamma_cost = 1, lambda_cost = 0.95, and one multiplier trajectory per seed. BSA-Penalty-PPO uses
#    a fixed penalty; BSA-Unconstrained-PPO omits the constraint term. These are the mechanisms as
