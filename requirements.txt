# Implementation notes:
# - The per-slot action is a length-N joint-autoregressive sequence over the flat token alphabet
#   Discrete(1 + K*B*P), with one joint slot log-probability and one PPO clipped ratio per slot.
# - BSA-C-PPO uses projected Lagrangian multiplier updates with one shared vector cost critic.
#   BSA-Penalty-PPO uses a fixed penalty, while BSA-Unconstrained-PPO omits the constraint term.
# - These are implementation mechanisms; no theoretical convergence or safety guarantee is claimed.
